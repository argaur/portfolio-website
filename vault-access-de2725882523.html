Vault Access — App Info & Privacy Policy

life-os is a personal tool built and used by one person, Gaurav Gupta. It reads and writes his own Obsidian vault, which he stores in his own Google Drive.

This page exists to satisfy Google Cloud's OAuth consent screen requirements for an app homepage and a privacy policy. It is not linked from anywhere on this site and is not meant for a general audience.

Privacy Policy

This app requests access to Google Drive using the scope https://www.googleapis.com/auth/drive. That access is used only to read and write files inside one folder: Gaurav's own Obsidian vault.

No data collected through this access is shared with any third party. No data is sold, sold on, or used for advertising. The only account this app is ever authorized against is Gaurav's own personal Google account.

The credential this app generates is stored locally, on Gaurav's own machine and on a private server he controls. It is never committed to a public repository.

This app has no other users. If that ever changes, this policy will change with it.

Terms of Service

This app is for Gaurav Gupta's own personal use only. It is not offered as a service to anyone else, and there is no signup or account creation for other users.

It connects to Google Drive to read and write one folder: Gaurav's own Obsidian vault. It does not access, read, or modify any other file or folder in the account.

This app is provided as-is, with no warranty, since it has exactly one user who is also its developer.

These terms may change at any time. Since there is only one user, a change takes effect immediately.
