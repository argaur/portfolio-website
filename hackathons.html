Notice, Explained

A GST DRC-01C notice shows one number and no reason. This tool traces the gap row by row, explains it with a grounded OpenAI call, and drafts a review-only reply.

The clock · 5 days

Aug 24Aug 28
  • Aug 24The brief narrowed to 10 government platforms. We researched all ten.
  • Aug 25Picked the Cyber Crime portal and CPGRAMS.
  • Aug 27Dropped that idea. Switched to the GST DRC-01C notice and locked the problem.
  • Aug 28Approved the final flow, built it, deployed it and submitted.
  • Round 2The Top 250 got a week of mentorship. We added a risk screen and a Hindi or English question box, and resubmitted.

Hours were not logged. This was a team event, before I started tracking time.

My part

Built with Kriti Kandhari Kapoor, from my cohort. We shared every role, from research to build.

One rule shaped the build: code decides, the model explains. The math is plain code with tests. The model only explains rows the code has already checked.
